# 查看 PDF、图片与 HTML

<span class="version-badge">适用于 HorseMD v0.13.242</span>

HorseMD 不只是 Markdown 编辑器，也可以作为工作区的阅读中枢：PDF 和常见图片文件可以直接在标签页中打开查看，无需切换到其他应用。

## 支持的格式

- **PDF**:`.pdf`
- **图片**:`.png`、`.jpg` / `.jpeg`、`.gif`、`.webp`、`.svg`、`.bmp`、`.ico`、`.avif`
- **HTML**:`.html`、`.htm`

## 打开方式

与文档相同，任选其一：

- 在工作区文件树中点击文件。
- 按 `Ctrl/Cmd+O` 在打开对话框中选择。
- 双击已关联的文件，或把文件直接拖到 HorseMD 窗口。
- 通过启动参数把文件交给 HorseMD。

查看器标签是**只读**的：不会产生未保存状态，也不会被 Cmd/Ctrl+S 覆写。查找替换、源码 + 预览分屏等编辑功能在查看器标签上不可用。

## PDF 查看

PDF 标签使用 Chromium 内置查看器，自带翻页、缩放、页面搜索和目录侧栏，无需学习新的操作方式。

## 图片查看

图片标签顶部有一个小工具栏：

- **− / +**：缩小 / 放大（也可按住 `Ctrl/Cmd` 滚动滚轮或用触控板捏合连续缩放）
- **适应**：缩放回适合面板的大小
- **1:1**：按原始像素大小显示（双击图片可在适应与 1:1 之间切换）
- **⟳**：每次旋转 90°
- **⤓**：把图片另存到任意位置

放大后可以直接滚动或拖动滚动条平移查看细节。

## HTML 预览

`.html` / `.htm` 文件默认以**渲染预览**打开：页面在隔离的沙箱中运行（可以执行脚本、发起网络请求，但无法访问你电脑上的其他本地文件或编辑器本身），所见即该网页在浏览器中的效果。

标签左上角的**源码**按钮可以切换为源码编辑（带语法高亮的代码编辑器）；编辑后点回**预览**会先保存，再重新渲染页面。

- 预览每页从磁盘重新加载，输入源码时不会实时刷新。
- 超过 2MB 的 HTML 文件会直接以源码模式打开。
- 每个文件的预览/源码偏好会被记住，下次打开时恢复。
- 目前仅桌面版支持 HTML 预览。

## 文件缺失或损坏

如果文件在打开后被移动、删除，或图片数据无法解码，标签页会显示"文件缺失或无法读取"的提示和文件路径，标签可以正常关闭。重启 HorseMD 时，查看器标签会随会话恢复，并重新读取文件。

::: tip 移动端
图片与 PDF 查看目前仅桌面版支持。
:::
