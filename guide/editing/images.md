# 图片与图床

<span class="version-badge">适用于 HorseMD v0.12.10</span>

## 插入图片

可以将图片粘贴到正文、拖入编辑器，或通过斜杠菜单插入图片。代码块获得焦点时，粘贴和拖入保持代码输入行为，不会被图片处理拦截。

本地相对路径会以当前 Markdown 文件所在目录解析。例如：

```md
![界面截图](./images/interface.png)
```

移动 Markdown 文件时，应同时移动相对路径引用的图片目录。网络图片使用 `https://` 或受信任的 `http://` 地址，加载速度取决于远程服务器。

## 查看图片路径

富文本视图中，每张图片下方会常驻显示该图片在 Markdown 源中的路径（如 `./assets/interface.png` 或完整 URL），方便核对图片来源。超长路径会中间截断，鼠标悬停可看完整内容；`data:` 内嵌图片显示“内嵌图片”。

路径角标仅供展示：不会进入文档内容、复制内容或 PDF 导出。不需要时可在“设置 → 编辑器 → 显示图片路径”关闭。

## 查看大图

双击正文图片可以打开灯箱，按 Escape 或点击背景关闭。图片说明使用 Markdown 图片的替代文字；替代文字也有助于图片加载失败和无障碍阅读。

## 自定义图床

点击顶栏图片按钮，或进入“设置 → 图床”，填写类似 `picgo upload` 的上传命令。配置后，HorseMD 会把粘贴、拖入或选择的图片写入临时文件，执行：

```text
<你的命令> "<临时图片路径>"
```

命令最后输出的 `http://` 或 `https://` 地址会作为图片链接插入。按钮上的强调色圆点表示已经配置。

::: warning 先在终端验证命令
HorseMD 不负责安装 PicGo 或其他上传工具。命令应在终端中可以独立运行，并且只把可信 URL 输出到标准输出。留空会恢复默认本地图片行为。
:::

## 本地图片存放位置（附件文件夹）

未配置图床命令时，粘贴、拖入或选择的图片默认复制到文档同级的 `assets/` 文件夹，并以相对路径插入文档。进入“设置 → 文件与图片 → 附件文件夹”，可以像 Typora 一样选择“插入图片时”的存放位置：

- 复制图片到当前文件夹（./）
- 复制图片到 `./assets` 文件夹（默认）
- 复制图片到 `./${filename}.assets` 文件夹（按文档名命名，例如 `笔记.assets`）
- 复制到指定路径：支持相对或绝对路径，可用 `${filename}` 代表当前文件名

配置图床命令后，上传优先，此设置仅在本地存放时生效。粘贴到未保存的新文档的图片会先放在临时目录，首次保存时自动迁移到上述位置并改写为相对路径。
