# drawio 图表

<span class="version-badge">适用于 HorseMD v0.13.208</span>

HorseMD 支持直接打开和编辑 [draw.io / diagrams.net](https://www.drawio.com) 格式的图表文件（`.drawio`）。图表以独立标签页打开，使用本地打包的 drawio 官方编辑器，**完全离线可用**，保存时仍是标准的 `.drawio` XML 文件，可以继续在 draw.io、diagrams.net 或其他兼容工具中打开。

## 新建图表

点击左侧边栏顶部工具行的**图表图标**（新建文件按钮旁边），会创建一个 `untitled.drawio` 文件并打开空白画布；输入文件名后回车确认。该按钮仅在桌面版可用。

## 编辑要点

图表编辑器与 draw.io 官方编辑器一致：

- **形状库**：左侧形状面板拖入流程图、UML、网络拓扑等图形
- **连线**：悬停在图形边缘拖出连线
- **多页文档**：底部页面标签可以添加、复制和切换页面，保存时全部保留
- **文本与样式**：右侧面板调整填充、边框、字体

编辑器界面与 [app.diagrams.net](https://app.diagrams.net) 一致：完整菜单栏、工具栏、左侧形状库和右侧样式面板，可以按 draw.io 的习惯操作。

## 保存

图表与其他文档使用相同的保存模型：编辑后标签页出现未保存标记，`Cmd/Ctrl+S` 保存到磁盘。没有修改时保存不会产生多余写入。

如果文件在 HorseMD 之外被修改，重新聚焦时会按普通文档的规则提示外部修改。

## 导出 PNG / SVG

在图表标签页上右键，选择**导出图表为 PNG** 或**导出图表为 SVG**；也可以在命令面板（`Cmd/Ctrl+P`）中搜索这两个命令。选择保存位置后，HorseMD 会把当前图表渲染为 PNG 位图或 SVG 矢量图写入所选路径。

## 损坏文件

如果 `.drawio` 文件内容不是有效的图表文档（例如被其他程序覆盖），HorseMD 会显示空白画布并在顶部给出一次性提示，不会修改原文件内容。

## 移动端

drawio 图表编辑目前仅桌面版支持。移动端打开 `.drawio` 文件会显示占位提示，侧边栏也不显示新建图表按钮。
